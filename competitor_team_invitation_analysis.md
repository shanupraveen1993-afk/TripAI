## 1. SEMRUSH - Enterprise-Grade Team Management

### User Flow
```
Buy Additional Seats → Navigate to User Management → Click "Invite Users"
→ Enter Email Addresses → Send Invitations → Users Accept via Email
→ Auto-granted Access with Shared Limits
```

### Payment & Limits
- **Base plan:** 1 user seat included
- **Additional users:** $20/month (base) + toolkit costs
  - SEO Toolkit users: $45-$100/user (tier-dependent)
  - Traffic & Market Toolkit: $289/user
  - AI Visibility Toolkit: $99/user

### User Roles (4-Tier System)
| Role | Permissions |
|------|-------------|
| **Owner** | Full control: add/remove users, manage subscriptions, appoint admins |
| **Admin** | Manage users, edit limits, view all folders, monitor activity |
| **User** | Access most toolkits, create personal folders (no Traffic & Market/AI Visibility) |
| **Guest** | Limited access to specific shared assets only |

### Key Features
✅ **Shared Limits:** All users share subscription limits by default
✅ **Guest-to-User Conversion:** Can upgrade guests to full team members
✅ **Asset Sharing:** Granular sharing at tool/folder/document level
✅ **Payment Blocker:** Users with existing paid plans cannot accept invitations

### Accessibility: ⭐⭐⭐⭐ (4/5)
- Clear multi-step process with purchase-first requirement
- Dashboard centralized at `/corporate/account/users`

### Reliability: ⭐⭐⭐⭐⭐ (5/5)
- Email-based invitations prevent unauthorized access
- Role-based permissions ensure security
- Prevents conflicts with existing subscriptions

## 2. AHREFS - Usage-Based Flexibility

### User Flow
```
Invite Team Members for Free → Members Accept Invitation
→ Usage Tracking Begins → Pay Only for Active Users (>5 reports/month)
```

### Payment & Limits
- **Innovative Model:** Inactive users are FREE
- **Active user cost:** $40-$80/month (plan-dependent)
- **Free usage threshold:** Up to 5 reports/month per user = $0

### Pricing Tiers & Seats
| Plan | Base Price | User Seats |
|------|-----------|------------|
| **Starter** | $29/mo | 1 seat |
| **Lite** | $129/mo ($108/mo annual) | 1 seat |
| **Standard** | $249/mo ($208/mo annual) | Multiple seats |
| **Advanced** | $449/mo ($374/mo annual) | Many seats |
| **Enterprise** | $1,499/mo ($1,249/mo annual) | Unlimited seats |

### User Roles (3-Tier System)
| Role | Permissions |
|------|-------------|
| **Owner** | Full financial control: pay bills, manage subscriptions, add users, change roles |
| **Admin** | Operational control: manage subscriptions, add users, change roles, workspace settings |
| **Member** | Standard access only, no admin capabilities |

### Key Features
✅ **"Invite First, Pay Later":** Add entire team immediately, no upfront cost
✅ **Shared Workspace Limits:** All members share workspace quotas
✅ **Bulk Invitations:** Invite multiple members simultaneously
✅ **Cost-Effective:** Light users (≤5 reports/mo) cost nothing

### Accessibility: ⭐⭐⭐⭐⭐ (5/5)
- Zero friction: Invite without purchasing seats first
- Transparent usage tracking

### Reliability: ⭐⭐⭐⭐ (4/5)
- Clear role definitions
- Usage-based billing reduces overpayment risk

## KEY PATTERNS IDENTIFIED

### 🏆 Best Practices from Competitors

#### 1. **Pricing Models (2 Successful Approaches)**

**A. Usage-Based (Ahrefs Model)**
- ✅ Invite unlimited users for free
- ✅ Pay only for active users
- ✅ Free threshold (5 reports/month)
- 💡 **Why it works:** Removes friction, encourages team growth

**B. Purchase-First with Clear Costs (Semrush Model)**
- ✅ Transparent per-user pricing
- ✅ Separate base + toolkit costs
- ✅ Shared limits system
- 💡 **Why it works:** Predictable budgeting, prevents surprise costs

#### 2. **User Role Systems**

**3-Tier System (Ahrefs):** Simple, easy to understand
- Owner → Admin → Member

**4-Tier System (Semrush):** Granular control
- Owner → Admin → User → Guest

💡 **Recommendation:** 3-tier system balances simplicity with control

#### 3. **Invitation Flow Patterns**

**Low-Friction (Best):**
```
Invite → Email → Accept → Auto-Access
```
Used by: Ahrefs, Semrush

**High-Friction (Avoid):**
```
Contact Sales → Quote → Contract → Manual Provisioning
```
Used by: Sensor Tower, data.ai

#### 4. **Payment Limit Strategies**

| Strategy | Used By | Pros | Cons |
|----------|---------|------|------|
| **Shared Limits** | Semrush, Ahrefs | Fair resource distribution | Can cause team conflicts |
| **Per-User Allocation** | Semrush (option) | Clear individual quotas | More complex to manage |
| **Unlimited for Tier** | Mobile Action Enterprise | No limit concerns | Higher cost |

### Key Design Principles (From Competitor Analysis)

#### ✅ DO's:

1. **Clear Seat Visibility**
   - Show "X/Y seats used" prominently
   - Display on both main page and invite modal

2. **Transparent Pricing**
   - Show cost per additional user
   - Link to pricing page
   - No hidden fees

3. **Email-Based Invitations**
   - Send verification emails
   - Show pending invitation status
   - Allow resending invitations

4. **Role Selection**
   - Dropdown with 2-3 clear roles
   - Tooltip explaining each role's permissions
   - Default to "Member" (safest)

5. **Bulk Invitations**
   - Allow multiple email entries
   - "Add another" button for UX
   - CSV upload for large teams (optional)

6. **Upgrade Path**
   - Always show upgrade CTA when near limits
   - One-click access to pricing page
   - Show benefits of upgrading

#### ❌ DON'Ts:

1. **Don't Hide Limits**
   - Never let users hit walls unexpectedly
   - Show limits before they try to invite

2. **Don't Require Sales Contact**
   - Self-service for standard plans
   - Sales only for custom enterprise needs

3. **Don't Overcomplicate Roles**
   - Max 3-4 role types
   - Clear permission differences

4. **Don't Block Invitations on Free Plans**
   - Allow invites with upgrade prompts
   - Show value before demanding payment

## CONCLUSION

### Best Model to Adopt: **Hybrid Approach**

**Combine best practices from Ahrefs + Semrush:**

1. **Free Tier Invitation** (Ahrefs style)
   - Allow 1-3 free invitations on free plan
   - Show upgrade prompt after limit
   - Create FOMO and viral growth

2. **Clear Pricing Model** (Semrush style)
   - Transparent per-seat costs
   - Visual seat usage indicators
   - Shared limits with optional allocation

3. **Simple 3-Tier Roles** (Ahrefs style)
   - Owner → Admin → Member
   - Clear permission differences
   - Easy to understand

4. **Self-Service Flow** (Mobile Action style)
   - No sales contact required
   - Instant invitation sending
   - Immediate team growth

### Expected User Flow:
```
User Signs Up (Free Plan - 1 seat)
     ↓
Completes onboarding, creates first project
     ↓
Sees "Invite Team" prompt/badge
     ↓

     ↓
```
