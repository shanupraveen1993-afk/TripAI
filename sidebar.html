SearchVector Sidebar Navigation

Analysis & Recommendations Based on Industry Leaders

Executive Summary

This document analyzes the current SearchVector sidebar navigation against 4-5 top ASO/SEO competitor tools (AppTweak, SensorTower, Ahrefs, Similarweb) and provides actionable recommendations to improve font hierarchy, spacing, and visual design without changing the font family or dashboard area.

Key Goal: Improve sidebar navigation scannability, hierarchy, and professionalism while maintaining current font family and not modifying the dashboard area.

Competitor Analysis Summary

1. AppTweak

  • Bold headings (600 weight) for primary categories
  • Regular weight (400) for sub-items
  • Clear 2-level hierarchy with icon badges
  • Descriptive subtitles under major items
  • "New" badges for recent features
  • Progressive disclosure (collapsible sections)

Font Hierarchy: Primary: 600 weight | Secondary: 400 weight | Clear 200-point weight difference

2. SensorTower

  • Multi-level font weight system:
    • Primary: 600 weight, 18px
    • Secondary: 400 weight, 15px
    • Subheaders: 600 weight, 24px (desktop)
  • Smooth transitions: 500ms cubic-bezier
  • Active states: Background color + icon rotation (90°)
  • Icon treatment: Consistent color system (white mobile, teal desktop)

Spacing: Mobile: 40px vertical | Desktop: Horizontal layout with 4px grid | Clear padding: 40px horizontal on list items

3. Ahrefs Help Center

  • Card-based layouts with 8px border radius
  • Folder icons for collection groupings
  • Article/item counts for context
  • 2-column grid for collections
  • Emphasis on discoverability through categorization

4. Similarweb

  • Bold formatting for section headers
  • Hover states with highlight mechanisms
  • Solution cards with subtitles
  • CTA buttons prominently positioned
  • Consistent class naming for spacing

Recommended Typography Hierarchy

(Without changing font family)

Level 1: Primary Navigation Items

  • Font Weight: 600 (Semibold)
  • Font Size: 15px
  • Text Transform: Capitalize (not uppercase)
  • Line Height: 20px
  • Color: #1A1A1A (inactive) / #FFFFFF (active)
  • Examples: My Projects, What's New

Level 2: Section Headers (Collapsible)

  • Font Weight: 600 (Semibold)
  • Font Size: 12px
  • Text Transform: UPPERCASE
  • Letter Spacing: 0.5px
  • Line Height: 16px
  • Color: #6B7280 (Gray-500)
  • Examples: SEARCH, GOOGLE ADS

Level 3: Sub-items (Under Sections)

  • Font Weight: 500 (Medium)
  • Font Size: 14px
  • Text Transform: Capitalize
  • Line Height: 20px
  • Color: #374151 (Gray-700)
  • Examples: Keyword Research, GSC Insights

Key Takeaways from Competitor Analysis

Implementation Priority

Phase 1 Typography & Font Weights (High Impact)

  1. Update font weights: Primary (600), Headers (600), Sub-items (500)
  2. Adjust font sizes: 15px, 12px, 14px respectively
  3. Fix text transform: Remove all caps from primary items
  4. Add letter spacing (0.5px) to section headers

Phase 2 Spacing & Layout (Medium Impact)

  1. Implement consistent padding system
  2. Add proper margins between groups
  3. Indent sub-items properly (32px left padding)
  4. Add breathing room between sections

Phase 3 Interactive States (Medium Impact)

  1. Add hover states with gray background
  2. Improve active state for sub-items (left border accent)
  3. Add smooth transitions (150-200ms)
  4. Implement icon rotation for expanded sections

Phase 4 Icons & Visual Polish (Low Impact)

  1. Standardize icon sizes
  2. Ensure consistent icon colors
  3. Add filled icons for active states
  4. Verify icon-text gaps

Final Recommendations Summary

✅ DO (Keep Current Font Family)

  1. Implement 3-level font weight system: 600 → 600 → 500
  2. Adjust font sizes: 15px → 12px → 14px
  3. Add letter spacing (0.5px) to uppercase headers
  4. Standardize icon sizes: 20px (primary), 16px (others)
  5. Increase vertical spacing between sections
  6. Add hover states with subtle backgrounds
  7. Improve active state indication (especially for sub-items)
  8. Add smooth transitions (150-200ms)
  9. Indent sub-items properly (32px)
  10. Add optional divider after primary navigation

❌ DON'T

  1. Change the font family (keep current)
  2. Modify dashboard/main content area
  3. Add too many colors (stick to orange accent + grays)
  4. Over-animate (keep transitions subtle and fast)
  5. Make section headers too large (12px is optimal)

Expected Impact

Improved Scannability Users can quickly distinguish between primary navigation, section headers, and sub-items due to clear visual hierarchy.
Better UX Hover states and smooth transitions provide better feedback, making the interface feel more responsive and polished.
Professional Look Consistent spacing, font weights, and icon treatment align with industry leaders (AppTweak, SensorTower, Similarweb).
Accessibility Improved contrast and font sizes make navigation easier to read and interact with.
Scalability The system can accommodate new menu items without breaking visual hierarchy.
