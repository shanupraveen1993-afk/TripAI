Option 1: padding: 12px 24px, radius: 8px, font: 14px, weight: 600

Use Option 1 for better touch targets and accessibility. Define button hierarchy: Primary (orange bg, white text), Secondary (white bg, orange border), Tertiary (no border, orange text). All buttons should have 44px minimum height.

4. TABLES 2 variants

Simple Table: Clean headers, minimal styling, use for most tables

Use Simple Table as default. Headers: 11px, uppercase, #999, 600 weight. Cells: 14px, #333, 400 weight. Padding: 12px vertical consistent for both. Border: 2px solid #f0f0f0 under header, 1px under rows. Reserve contained tables only for complex ranking/comparison data.

5. TYPOGRAPHY Multiple issues
Page titles: 32px (Page 1), 28px (Page 2), 24px (Page 3) - inconsistent
Body text: 14px and 13px found
Labels: 11px and 10px found
Font weights: 400, 500, 600, bold (too many)

ACTION: Define typography scale and stick to it

H1: 32px / 700 / #333 (main page titles)
H2: 24px / 700 / #333 (section headings)
H3: 18px / 600 / #333 (subsections)
Body: 14px / 400 / #666 (all body text)
Small: 12px / 400 / #999 (labels, metadata)
Weights: Use only 400, 600, 700 (remove 500)

💡 Recommendation

Apply complete typography system. Never use 13px or 10px. Line-heights: H1-H3 use 1.2-1.3, Body uses 1.6. This creates clear hierarchy and improves readability. Document this in a CSS file as reusable classes (.text-h1, .text-body, etc.).

Page 1: Label: 11px #999 | Value: 24px bold #333

Label: 11px, 400, #999, uppercase, letter-spacing: 0.5px

Layout: Label above value, left-aligned

Apply uniform sizing. All metric values must be 32px regardless of number length. For very small numbers (0-10), consider adding subtle background or border to give visual weight. Grid layout with equal-width columns for even spacing.

10. NUMBER FORMATTING No rules
Found: 29, 257, 2.7K, 444, 1.9K, 193.4K, 0.97%, 44.2
No consistent decimal rules
K/M abbreviation varies

ACTION: Define number formatting rules

Under 1,000: No decimals (257)
1,000-999,999: 1 decimal + K (2.7K, 193.4K)
1M+: 1 decimal + M (1.5M)
Percentages: Always 2 decimals (0.97%)
Decimals in small numbers: 1 decimal max (44.2)

💡 Recommendation

Implement all rules using a JavaScript formatting function. Create a utility function like formatNumber(value, type) that handles all cases consistently. Document edge cases (negative numbers, zero, very large numbers). Use this function everywhere numbers are displayed.

11. SPACING & LAYOUT Too many values
Card padding: 20px, 16px, 18px (varies)
Section gaps: 15px, 20px, 30px (varies)
Button padding: 8px, 10px, 12px, 14px (too many)
Border radius: 4px, 6px, 8px, 12px, 20px (too many)

ACTION: Use 8px grid system

Spacing values: 4, 8, 12, 16, 24, 32, 48, 64px only
Border radius: 4px (small), 8px (medium), 12px (large), 20px (pill)
Component padding: 12px (tight), 16px (normal), 20px (comfortable), 24px (spacious)
Section gaps: 16px (tight), 24px (normal), 32px (large)

💡 Recommendation

Strictly enforce 8px grid. Never use 15px, 18px, or any non-multiple of 4. Create CSS variables for spacing (--space-1: 4px, --space-2: 8px, etc.). This creates consistent visual rhythm and makes design scalable. Remove all arbitrary spacing values from codebase.

12. ICONS Emoji only
All pages: Use emoji icons (📱, 🔍, 📊, 🎯, 📈, etc.)
Platform-dependent rendering
Inconsistent sizes due to different emoji shapes
No consistent spacing around icons

ACTION: Replace with SVG icon system

Icon library: Lucide Icons or Heroicons
Sizes: 16px (small), 20px (medium), 24px (large) only
Color: currentColor (inherits from text) or #ff6b35
Stroke width: 2px consistent

💡 Recommendation

Use Lucide Icons. Free, well-designed, consistent stroke width. Replace all emojis with SVG equivalents. Use 20px as default size for UI icons, 24px for feature icons. Color should inherit from parent text color for flexibility. Create icon component wrapper for consistent sizing.

13. COLORS Too many shades
Gray text: #999, #888, #777, #666 (4 different shades)
Borders: #e0e0e0, #f0f0f0, #ddd (3 different)
Backgrounds: #fafafa, #f9f9f9, #f5f5f5 (3 different)

ACTION: Define color system

Text primary: #333
Text secondary: #666
Text tertiary: #999
Border default: #e0e0e0
Background page: #f5f5f5
Background input: #f9f9f9
Brand orange: #ff6b35

💡 Recommendation

Remove all intermediate gray values. Use only #333, #666, #999 for text. Single border color #e0e0e0. Never use #777, #888, #ddd, #f0f0f0. Create CSS custom properties for all colors. Check all colors meet WCAG AA contrast ratio (4.5:1 for body text, 3:1 for large text).
