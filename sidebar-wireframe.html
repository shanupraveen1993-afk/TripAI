Typography & Spacing Specifications

Level 1: Primary Items

  • Font Weight: 600 (Semibold)
  • Font Size: 15px
  • Line Height: 20px
  • Padding: 10px 12px
  • Gap: 12px (icon-text)
  • Icon Size: 20px × 20px
  • Active BG: #FF6B1A
  • Hover BG: #F3F4F6

Level 2: Section Headers

  • Font Weight: 600 (Semibold)
  • Font Size: 12px
  • Line Height: 16px
  • Text Transform: UPPERCASE
  • Letter Spacing: 0.5px
  • Padding: 8px 12px
  • Margin Top: 20px
  • Color: #6B7280
  • Icon Size: 16px × 16px

Level 3: Sub-items

  • Font Weight: 500 (Medium)
  • Font Size: 14px
  • Line Height: 20px
  • Padding: 8px 12px 8px 32px
  • Gap: 10px (icon-text)
  • Icon Size: 16px × 16px
  • Active BG: #FFF7ED
  • Active Border: 3px solid #FF6B1A
  • Active Color: #FF6B1A
  • Hover BG: #F3F4F6

Transitions & Effects

  • Hover Transition: 150ms ease-in-out
  • Icon Rotation: 200ms cubic-bezier
  • Chevron Rotation: 90deg (expanded)
  • Border Radius: 8px
  • Divider: 1px solid #E5E7EB
  • Divider Margin: 12px 0

Color System

  • Primary Orange: #FF6B1A
  • Orange Light BG: #FFF7ED
  • Gray Text: #374151
  • Gray Headers: #6B7280
  • Gray Icons: #6B7280
  • Hover BG: #F3F4F6
  • Border: #E5E7EB

Key Improvements

  • ✅ Clear 3-level font hierarchy (600→600→500)
  • ✅ Size differentiation (15px→12px→14px)
  • ✅ Letter spacing on headers (0.5px)
  • ✅ Hover states with smooth transitions
  • ✅ Active state with left border accent
  • ✅ Proper spacing & breathing room
  • ✅ Consistent icon sizing (20px/16px)
  • ✅ Sub-item indentation (32px)
